## 🧩 About

**The Forest overlay Menu** is a curated list of The Forest open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay viewer, item tracker
- **Quality-of-Life Helpers** — inventory catalog, crafting manager, overlay notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Survival Helpers
- overlay Overlay — highlight items, animals, and enemies
- Item Tracker — track resources and loot on screen
- Map overlay — show nearby points of interest
- Stats HUD — display health, hunger, and stamina

### 🎨 Inventory & Crafting
- Inventory Catalog — browse items and recipes
- Quick Craft Notes — organize crafting queues
- Storage Manager — manage containers and logs

### 🏋️ World Interaction
- Building Helper — show placement guides
- Enemy overlay — mark hostile positions
- Loot Highlighter — highlight collectible items

| Parameter | Type | Default | Description |
